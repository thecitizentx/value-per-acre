03 / Understand

The math is simple.
The boundary is the choice.

Keep the measured value fixed within each scenario. Change only the acreage beneath it.

Value per acre=Measured valueDefined acreage

Gross development acreage

AG = AT + AR + AD + AC + AE

Taxable + roads + drainage + common space + easements / other. These must be distinct, non-overlapping areas.

Per taxable acre

VTA = V / AT

Per gross acre

VGA = V / AG

Percentage reduction

Δ% = [(VTA − VGA) / VTA] × 100

The percentage difference uses taxable-acre value as its baseline. If the measured value is zero, both rates are $0 and the percentage is undefined (N/A).

V = measured value  ·  A = acreage
T taxable  ·  G gross  ·  R roads  ·  D drainage  ·  C common  ·  E easements / other

Read the result in context

Results are only comparable when the acreage boundary is defined consistently.

Use a consistent value definition, assessment date, and treatment of shared land across scenarios. Saleable acreage is not automatically taxable acreage. The examples assume the entered taxable acres are the measured parcel area.

With a positive measured value, a larger denominator lowers reported value per acre; it does not change the project’s value. This tool compares value density, not tax revenue, service costs, or net fiscal impact.
